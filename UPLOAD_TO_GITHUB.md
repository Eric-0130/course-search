# GitHub upload / 上传 GitHub

This repository was initially published with ChatGPT assistance to https://github.com/Eric-0130/course-search.

## Review before applying

- Run the source and tests yourself before linking it on your resume.
- Review `Trie.java`, `CourseCatalog.java`, and `CsvCourseReader.java` and understand their implementation.
- This is a demo project with illustrative, **not official UCSD**, course data.
- The initial code was generated with AI assistance. Do not claim it was written entirely independently.

## Download and run

1. Visit https://github.com/Eric-0130/course-search.
2. Choose **Code → Download ZIP** or `git clone https://github.com/Eric-0130/course-search.git`.
3. Install JDK 17 or newer; check with `java -version` and `javac -version`.
4. Run `bash scripts/run.sh --query "CSE 12"` on Mac/Linux, or `scripts\run.bat --query "CSE 12"` on Windows.
5. Run `bash scripts/test.sh` or `scripts\test.bat`; expect 20 passed tests.

## Update your GitHub repository

Edit the project locally, then use:

```bash
git add .
git commit -m "Improve course search"
git push origin main
```

If you downloaded a ZIP rather than cloned the repository, clone it before using these Git commands.

## Resume

Once you have personally reviewed, tested, understood, and improved the code, add the real GitHub repository URL to your resume and describe your specific contribution accurately. Do not upload your personal resume to this public project unnecessarily.
